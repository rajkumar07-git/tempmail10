# TempMail10

A free temporary email website. One click gives you a disposable address and
password, with an inbox that stays live for 10 hours.

## Features
- Instant email address and password (copy buttons)
- 10-hour live countdown, then the mailbox is deleted automatically
- Inbox auto-refreshes every 8 seconds; emails open in a sandboxed viewer
- Outbox and Write section (demo only, messages are not delivered)
- Responsive, dark/light mode, no external libraries
- SEO ready: meta tags, Open Graph, JSON-LD schema, FAQ
- Reserved ad slots that do not shift the layout

## Setup
1. Download `index.html`.
2. Replace `YOUR-DOMAIN.com` with your real domain (canonical, og:url, JSON-LD).
3. Upload to any static host (GitHub Pages, Netlify, Vercel, cPanel).

## How it works
Mail is handled by the free [mail.tm](https://mail.tm) API. The site runs fully
in the browser, so no server is needed.

## Disclaimer
Do not use temporary mailboxes for banking or sensitive accounts. Not for
spam, fraud or any illegal use.
